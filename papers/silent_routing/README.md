# Silent Routing (ICML 2026)

LaTeX sources and compiled PDF (`main.pdf`) for *Silent Routing: How Step Supervision Trains Transformers Where Outcome Supervision Stalls*.

```bash
tectonic -X compile main.tex
```

- `main.tex`, `body.tex`, `appendix.tex`, `main.bib` — manuscript sources
- `figures/` — TikZ/PGFPlots figures
- `main.pdf` — compiled paper

Code and animations live at the repo root: [`cpp/`](../../cpp/README.md), [`handcoded/`](../../handcoded/README.md), `src/`, and [`animations/`](../../animations/README.md).
